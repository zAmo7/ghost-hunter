ZAMO · SIN PRUEBAS

V1 - Medidor manual de pasos + observaciones de comportamiento.

Archivos:
- index.html
- manifest.webmanifest

Uso:
1. Abre index.html en un navegador o súbelo a GitHub Pages.
2. Durante una caza, toca PASO una vez por cada pisada que escuches.
3. Con 4 o más pasos, la app calcula intervalo, pasos/segundo y tendencia (estable/acelerando/desacelerando).
4. Registra observaciones claras para ordenar candidatos.

Nota: el medidor usa ritmo de pisadas; no afirma una velocidad física exacta en m/s sin una calibración de distancia.
